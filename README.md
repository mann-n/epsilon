# epsilon67 — сайт-визитка команды

**Epsilon67** — это сайт команды, созданный для представления участников, их ролей и совместной деятельности. Он отражает индивидуальность команды, её идеи, цели и подход к работе. Сайт объединяет всю основную информацию о команде в одном удобном и современном пространстве.

**Назначение проекта.** Основная цель сайта — познакомить пользователей с командой Epsilon67, рассказать о её участниках, распределении обязанностей и проектной деятельности. Сайт также служит площадкой для демонстрации командных возможностей, идей и результатов работы.

Проект выполнен в рамках отборочного задания Всероссийского хакатона «Волга.ТОП» (2026).

- Репозиторий: https://github.com/mann-n/epsilon.git
- Сайт: https://mann-n.github.io/epsilon/

## 2. Реализованное решение

Разработан сайт-визитка команды. На сайте реализованы все обязательные разделы из задания:

- **Шапка** — название команды, эмблема, девиз, меню;
- **О команде** — несколько предложений о том, кто мы и почему участвуем в хакатоне;
- **Участники** — карточка каждого участника: имя, фото, роль в команде, группа, навыки, контакт;
- **Навыки команды** — языки, технологии и инструменты, с которыми работали участники;
- **Проекты** — выполненные работы и идеи, которые команда хочет реализовать;
- **Контакты и подвал страницы** — способ связаться с командой и ссылка на репозиторий.

Сайт не содержит текстов-заглушек, пустых блоков и нерабочих ссылок. Данные об участниках хранятся отдельно от разметки.

## 5. Установка и запуск

Сайт можно открыть как на компьютере, так и на мобильном устройстве.

**Онлайн:** https://mann-n.github.io/epsilon/

**Локально.** Требуется браузер и Git.

```bash
git clone https://github.com/mann-n/epsilon.git
cd epsilon
```

Затем откройте файл `index.html` в браузере.
